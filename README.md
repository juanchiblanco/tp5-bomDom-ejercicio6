# TP5 - BOM y DOM - Ejercicio 6

## Descripción

Este proyecto consiste en una aplicación web desarrollada con HTML, Bootstrap y JavaScript que implementa un **temporizador regresivo**. El usuario puede ingresar manualmente un tiempo inicial (en segundos), y al presionar "Iniciar", el contador comienza a decrementar automáticamente cada segundo.

La interfaz incluye los siguientes botones funcionales:
- **Iniciar**: Comienza la cuenta regresiva desde el valor ingresado.
- **Pausar**: Detiene el temporizador sin reiniciarlo.
- **Reset**: Reinicia el contador al valor original ingresado por el usuario.

La lógica está basada en el uso de funciones del **BOM** (como `setInterval` y `clearInterval`) y manipulación del **DOM** para actualizar visualmente el tiempo restante.

## Tecnologías utilizadas

- **HTML5** (estructura del proyecto)
- **CSS** y **Bootstrap** (estilo visual)
- **JavaScript** (lógica del temporizador e interacción con el DOM)

## Ejecución

- Clonar o descargar el proyecto en tu computadora.
- Verificar la ruta del script para interactuar con los diferentes programas.
- Abrir el archivo index.html con un navegador web.
